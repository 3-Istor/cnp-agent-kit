# Working on this repository

- Skills follow the Agent Skills format: a folder with `SKILL.md`, YAML front
  matter `name` and `description`, the body under 150 lines, details in
  `reference/` files linked from the body.
- The `description` decides when a model loads the skill: say what it does
  and when to use it, with the words users use.
- Never state a platform fact that is not true on CNP today. Check it in the
  CMP, template or chart repositories first.
- A rule belongs in `doctrine/rules.md` with an ID; guides link to it.
